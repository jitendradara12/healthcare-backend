# Healthcare Backend

### Setup

1. clone, activate venv and install requirements

```bash
git clone https://github.com/jitendradara12/healthcare-backend
cd healthcare-backend

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

4. create .env (use .env.example as a reference)
5. Run the server:

```bash
python manage.py runserver
```
